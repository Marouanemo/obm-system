<p class="tldr"><strong>En bref.</strong> Un constructeur comme Wix permet de lancer vite un site simple, mais vous louez la plateforme et vous en acceptez les limites. WordPress est souple, à condition d’assurer une maintenance régulière de ses extensions. Un site codé sur mesure demande un investissement de départ plus élevé, et vous donne en retour la vitesse, la sécurité, un back-office pensé pour vous et la propriété complète du code. Le bon choix dépend de ce que le site doit faire.</p>
<h2>Wix et les constructeurs : rapides à lancer</h2>
<p>Un constructeur en ligne réunit hébergement, modèles et éditeur visuel. On peut publier un site en quelques jours, sans développeur. Les limites apparaissent avec le temps :</p>
<ul>
<li><strong>Un abonnement permanent</strong> : le site n’existe que tant que vous payez la plateforme.</li>
<li><strong>Une propriété limitée</strong> : le site ne s’exporte pas vers une autre solution ; changer de technique, c’est le refaire.</li>
<li><strong>Des performances encadrées</strong> : le code généré et les scripts de la plateforme pèsent sur la vitesse mobile.</li>
<li><strong>Un référencement possible mais contraint</strong> : structure, balises et données structurées dans les limites de l’outil.</li>
</ul>
<h2>WordPress : souplesse et maintenance</h2>
<p>WordPress est un logiciel libre, très répandu, avec des milliers de thèmes et d’extensions. Cette richesse a un revers : chaque extension doit être mise à jour, et une extension abandonnée ou mal codée devient une faille ou un ralentissement. Un site WordPress sérieux suppose donc un hébergement adapté, des mises à jour suivies, des sauvegardes et une surveillance de sécurité.</p>
<h2>Le site sur mesure : code natif et statique</h2>
<p>Un site codé sur mesure est construit pour votre activité, sans thème ni empilement d’extensions. Les pages publiées sont des fichiers légers, servis directement :</p>
<ul>
<li><strong>Vitesse</strong> : peu de code à charger, des pages rapides sur mobile.</li>
<li><strong>Sécurité</strong> : pas de base de données ni d’extension exposée sur les pages publiques.</li>
<li><strong>Back-office autonome</strong> : vous modifiez vos textes, vos articles et vos réalisations sans développeur.</li>
<li><strong>Propriété totale</strong> : le code, le nom de domaine et les accès vous appartiennent.</li>
<li><strong>Référencement maîtrisé</strong> : structure, balises, données structurées et maillage décidés page par page.</li>
</ul>
<p>C’est l’approche que nous utilisons pour nos clients, et pour notre propre site.</p>

<h2>Comment choisir</h2>
<ul>
<li>Un besoin temporaire ou un test : un constructeur suffit.</li>
<li>Un site éditorial avec beaucoup de contributeurs, et une équipe pour le maintenir : WordPress peut convenir.</li>
<li>Un site qui doit générer des demandes, se charger vite, durer et vous appartenir : le sur mesure.</li>
</ul>
<p>Avant de changer de technique sur un site existant, posez-vous les bonnes questions : voir <a href="/blog/refonte-site-5-questions/">les 5 questions avant une refonte</a>.</p>
<h2>Questions fréquentes</h2>
<h3>Un site sur mesure est-il plus difficile à modifier ?</h3>
<p>Non, si le back-office est livré avec le site. C’est la condition pour que vous restiez autonome.</p>
<h3>Peut-on passer de WordPress ou de Wix à un site sur mesure ?</h3>
<p>Oui. Les contenus sont repris, les anciennes adresses redirigées (301) vers les nouvelles, et le référencement est préservé.</p>
<h3>Le sur mesure coûte-t-il toujours plus cher ?</h3>
<p>Au départ, souvent. Sur trois ans, l’absence d’abonnement de plateforme et une maintenance plus légère réduisent l’écart, et le site rapporte davantage s’il convertit mieux.</p>
<h3>Comment vérifier la vitesse d’un site ?</h3>
<p>Avec PageSpeed Insights de Google, en mode mobile : il mesure le temps d’affichage et la stabilité de la page.</p>
